## About the Project
 
FanTech AI Chatbot is a domain-specific AI assistant designed to serve the customers of FanTech, a ceiling fan manufacturing company. Instead of waiting for email replies or navigating long FAQ pages, users can simply chat and get immediate answers.
 
This project demonstrates a real-world application of AI in the customer support domain, built with a modern React + Vite frontend and deployed on Vercel for production use.
 
---
 
## Features
 
- AI-powered conversations — Understands and responds to customer queries intelligently
- Real-time responses — Instant answers without any support agent involvement
- Domain-specific knowledge — Focused on FanTech products, installation, and troubleshooting
- Responsive design — Works seamlessly on desktop and mobile devices
- Clean UI — Minimal and user-friendly chat interface

## Getting Started
 
### Prerequisites
 
Make sure you have the following installed:
 
- [Node.js](https://nodejs.org/) (v16 or higher)
- npm or yarn
### Installation
 
1. Clone the repository
   ```bash
   git clone https://github.com/kchirag2023/fanTech-AI-Chatbot.git
   cd fanTech-AI-Chatbot
   ```
 
2. Install dependencies
   ```bash
   npm install
   ```
 
3. Start the development server
   ```bash
   npm run dev
   ```
 
4. Open your browser and visit `http://localhost:5173`
### Build for Production
 
```bash
npm run build
```
